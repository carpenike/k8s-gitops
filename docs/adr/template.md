# ADR template

Headings follow MADR v4.0.0, which is CC0-1.0. hve-core embeds that
template in `.github/instructions/project-planning/adr-standards.instructions.md`.
This file keeps the headings used in this repo and drops the rest of the
MADR optional sections.

```markdown
---
status: proposed
date: YYYY-MM-DD
decision-makers:
---

# Title

## Context and Problem Statement

## Decision Drivers

## Considered Options

## Decision Outcome

Chosen option: "...", because ...

### Consequences

## Pros and Cons of the Options

### Option
```

Status values: proposed, accepted, rejected, deprecated, superseded.
